# 🌿 My Garden Notebook

### A cozy digital space to plan, organize, and grow.

Keep your projects, tasks, notes, and everyday thoughts together in one little garden.

[**🌱 Open Live Demo**](https://hadiswebpro.github.io/MyGardenNoteBook/)

</div>

## ✨ Features

- **Dashboard** — Get a quick overview of your projects, tasks, notes, and upcoming deadlines.
- **Project organization** — Create projects, choose colors, and track progress.
- **Task management** — Add, edit, complete, and delete tasks; optionally assign due dates and projects.
- **Notes & journal** — Keep notes and journal entries in one place, with colors and pinning.
- **Calendar** — See dated tasks and upcoming reminders at a glance.
- **Search and filtering** — Find tasks and notes more easily.
- **Personalization** — Switch between light and dark themes.
- **Local data storage** — Your garden data is saved in your browser.
- **Backup and restore** — Export your data and import it later.
- **Installable PWA** — Add the app to a supported device and access previously cached content offline.

## 🎨 Design

The interface uses a warm, nature-inspired palette with burgundy, crimson, bronze, olive green, forest green, and soft cream.

## 🚀 Run Locally

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

```bash
git clone https://github.com/hadiswebpro/MyGardenNoteBook.git
cd MyGardenNoteBook
npm install
npm run dev
```

Vite will print a local development URL in your terminal.

### Production Build

```bash
npm run build
npm run preview
```

The build command runs the TypeScript check and creates the production bundle.

## 📦 Deployment

The app is deployed with GitHub Pages.

**Live website:** https://hadiswebpro.github.io/MyGardenNoteBook/

## 💾 Your Data

Projects, tasks, and notes are stored locally in the browser using Local Storage. They are not automatically synced between browsers or devices. Use the app's backup/export option before clearing browser data or moving to another device.
